# test-agonas: Agonas To-Do

A tiny vanilla HTML/CSS/JS to-do app used as a playground for the
[GitAssign](https://agentskills.io) issue-triage skill. Open `index.html` in a browser, no build step.

## Features
- Add, complete and delete tasks
- Remaining-task counter

## Contributing
Browse the open issues, comment on the one you want (say why you're a good fit), and the maintainer
will triage applicants.

| Issue | Difficulty |
|---|---|
| Mobile layout overflows | starter |
| Persist tasks across reloads | intermediate |
| Due dates, filters and a state store | advanced |
